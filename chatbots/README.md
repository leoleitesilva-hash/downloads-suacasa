# Meus Chatbots — Sua Casa Mais Segura

Coleção de chatbots prontos para o produto **"Sua Casa Mais Segura"** (guia gratuito em 3 passos + ebook).

Cada arquivo é um prompt completo, pronto pra copiar e colar na plataforma que você usar (ChatGPT/GPT personalizado, ManyChat, Typebot, BotConversa, Zaia, etc.).

## Os chatbots

| Arquivo | Chatbot | Pra que serve |
|---|---|---|
| [chatbot-entrega-brinde.md](chatbot-entrega-brinde.md) | 🎁 Bot de Entrega do Brinde | Entrega o guia gratuito no WhatsApp, captura o lead e aquece pra oferta |
| [chatbot-vendas-whatsapp.md](chatbot-vendas-whatsapp.md) | 💬 Bot de Vendas (SPIN) | Conduz a conversa de venda do ebook usando perguntas SPIN e contorna objeções |
| [chatbot-gpt-consultor.md](chatbot-gpt-consultor.md) | 🛡️ GPT Consultor de Segurança | GPT personalizado que responde dúvidas de segurança residencial e recomenda o guia |
| [vps/](vps/) | 🚀 Hospedagem na VPS | Stack Docker completa (Evolution API + Typebot) com passo a passo de instalação |

## Como usar

1. Abra o arquivo do chatbot que você quer.
2. Copie o bloco de prompt inteiro (entre as marcações de código).
3. Cole na plataforma:
   - **GPT personalizado**: cole em "Instructions" ao criar o GPT.
   - **Plataformas de WhatsApp** (Zaia, BotConversa com IA, etc.): cole no campo de prompt/persona do agente.
4. Ajuste os campos entre `[COLCHETES]` com seus dados (link do PDF, preço, link de checkout).
